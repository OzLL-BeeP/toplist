## 📊 FYP (For You Page) Algorithm

### Free User
- Base visibility: 100%
- Reach: 10,000 users

### PRO User
- Visibility: +2% boost
- Reach: ~10,200 users

### PREMIUM User
- Visibility: +5% boost
- Reach: ~10,500 users

### Factors Affecting FYP Position
1. Number of likes (weighted 40%)
2. Number of comments (weighted 30%)
3. Rating score (weighted 20%)
4. User tier (weighted 10%)
5. Time since posted (newer = higher)
